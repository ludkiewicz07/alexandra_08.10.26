##Данный релиз содержит готовую версию программы для потоковой обработки файлов FASTA и автоматическую Sphinx-документацию кода.
##Инструкция по установке и запуску
1. Установка необходимых пакетов
Для корректной сборки HTML-документации проекта требуются библиотеки Sphinx. Установите их командой в терминале:
```bash
pip install sphinx sphinx-rtd-theme
```
##2. Сборка и просмотр документации
Чтобы сгенерировать веб-страницы документации из исходных комментариев кода, выполните в терминале следующие шаги:
1. Перейдите в папку документации проекта:
   ```bash
   cd docs
   ```
2. Запустите сборку HTML-страниц:
   ```bash
   make html
   ```
3. Для просмотра готовой документации откройте в браузере файл: `docs/build/html/task.html` (или `modules.html`).
##3. Запуск основной программы
Для тестирования работы классов `Seq` и потокового генератора `Fasta_Reader` запустите скрипт:
```bash
python3 task.py
```
